当前浏览器不支持 Web Serial。请改用桌面版 Chrome、Edge 或支持该能力的 Firefox。

浏览器只允许在 HTTPS 或 localhost 页面刷写设备。GitHub Pages 部署后会自动满足 HTTPS 条件。

先选择已支持的型号，并完成上方确认。

浏览器没有找到串口？

换用可传输数据的 USB 线，并关闭正在占用串口的监视器。若设备未自动进入下载模式，按住 BOOT，再点击刷入；开始连接后可短按 RESET。

Safari、iOS 与多数移动浏览器不提供 Web Serial；请在桌面浏览器完成刷写。

开始前检查

  • 安全页面正在检查 HTTPS / localhost
  • Web Serial正在检查浏览器能力
  • 串口速率固定使用 115200，匹配当前硬件链路
  • 型号不会自动判定浏览器只能识别 ESP32-S3，不能识别具体屏幕板型

刷写过程约需数分钟。保持页面可见，期间不要拔线或关闭浏览器。

从 USB 到第一张画面

  1. 1.0

    连接。

    用数据线连接设备，选择浏览器列出的串口。刷机台会先确认芯片家族为 ESP32-S3。

  2. 2.0

    写入。

    Factory 镜像从 0x000000 写入，包含 bootloader、分区表与应用；空白设备不需要另刷其他文件。

  3. 3.0

    配网。

    重启后扫描屏幕上的 Wi‑Fi 二维码，完成首次联网；之后通过屏幕显示的局域网地址管理内容。

固件做什么

页面展示的每一项都来自当前固件实现；没有云服务、虚构指标或尚未适配的设备承诺。

LOCAL CONTROL

在局域网管理内容。

首次启动时完成 Wi-Fi 配置，之后可在浏览器中添加文字和图片、调整播放顺序，并控制屏幕亮度。

无需云账号 · 设置保存在设备中 · 中英文界面

MEDIA

上传图片与 GIF。

PNG 和 JPG 自动居中裁切为 480 × 480；不超过 2 MB、480 × 480 的 GIF 保留动画并按原尺寸居中播放。

最多 16 个内容页 · PNG · JPG · GIF

TF CARD

直接播放 TF 卡内容。

可从 TF 卡直接添加 PNG、JPG（.jpg）、GIF 与 ScreenDeck 480 × 480（.rgb565）文件，无需复制到机身存储。

扫描 3 层目录 · .jpg 后缀 · GIF ≤ 480 × 480

SMOOTH PLAYBACK

切页更流畅。

固件会缓存可预加载的静态图片，并采用整帧更新和淡入淡出，减少切换时的撕裂、闪烁与旧画面残留。

静态图片预加载 · 整帧更新 · 淡入淡出

DISPLAY CONTROL

调节显示与作息。

支持联网自动校时、日期时间叠层、5–100% 亮度和跨午夜定时息屏；息屏后可双击临时唤醒。

自动校时 · 定时息屏 · 双击唤醒
